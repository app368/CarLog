## Сделано — 21 ноября 2026, вечер: визиты

- **Визиты** вместо записей Records: дата, сервисный центр, пробег, примечание. Внутри — строки документа из сервиса: название, цена и одна или несколько работ из справочника (строка с несколькими работами — группа с общей ценой). Total — сумма регламентных строк, ремонт не входит. Старые записи удалены.
- **Документы в визите** — сверху Scan Document и Add from Photos, ниже миниатюры, внизу Share Document (страницы файлами на Mac) и Import from File; просмотр на весь экран с увеличением, там тоже есть Share.
- **Импорт визита** — файл JSON, который готовится по фото документа; записывается сразу, без предпросмотра, правки — в карточке; сообщение — только если работа не найдена или дата не совпала. Из карточки визита файл записывается прямо в этот визит; из списка (+ → Import Visit) визит ищется по дате: строки и пробег заменяются, центр и фото остаются; нет визита на эту дату — создаётся новый. Файлы визитов лежат в `Maintenance/Visits/`, в git не уходят.
- **Цены — из сметы** (документ Authorized Services): название работы и цена. Это ориентир на будущий визит, а не точный учёт, поэтому скидки, запчасти и labor из инвойса не переносим. Ремонт (тормоза и т. п.) не учитываем.
